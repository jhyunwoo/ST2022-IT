# ST2022-IT

## Overview

개인 실험 및 학습 프로젝트입니다. 이 저장소는 당시의 구현, 자료, 그리고 실험 결과를 보존하기 위한 개인 작업입니다.

## Technology

- 저장소에 포함된 소스·데이터·정적 자산
- 저장소의 소스와 설정 파일을 기준으로 재현 환경을 확인할 수 있습니다.

## Problem and approach

문제를 작은 실험으로 나누고 결과와 구현 과정을 기록합니다. 구현을 단순한 파일 모음에 그치지 않도록 소스·데이터·결과물을 함께 남겼습니다. 실행 전에는 포함된 설정과 의존성을 확인하고, 민감한 값은 환경 변수로 주입해야 합니다.

## Status

역사적 학습 또는 실험 결과를 보존하는 저장소입니다. 기능 추가보다 기록의 맥락과 재현 가능성을 우선합니다.
